# Hike Remote

## Run

This project is a Next.js 16 app using TypeScript, Tailwind CSS, and the App Router.

- Development: `npm run dev`
- Production build: `npm run build`
- Preview port: `5000`

The site currently uses structured mock data in `src/lib/data.ts` and is ready for a future CMS or booking integration. Brand assets from the import are retained at the project root.
